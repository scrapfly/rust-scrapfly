Module cloud_browser_downloads

Retrieve the files a Cloud Browser session downloaded.

Connect with BrowserConfig::downloads_stream: ScrapiumBrowser.getDownloads then returns each small file inline and each large one as an IO stream handle, which CloudBrowserDownloads reads in chunks with IO.read, so no CDP message is larger than one chunk. Without the option every file comes back inline, and the helpers read that shape too.

A session is any CdpSender: the chromiumoxide adapter ChromiumoxideCdp (feature chromiumoxide), or a closure Fn(String, Value) -> Future<Output = Result<Value, CdpError>> over a CDP client of your own.

ⓘ
let downloads = CloudBrowserDownloads::new(ChromiumoxideCdp::new(page));
downloads.wait_for("report.pdf", Duration::from_secs(60)).await?;
let paths = downloads.save_all("downloads").await?;
