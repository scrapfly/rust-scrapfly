Expand description

The proxy_pool parameter of the Web Scraping API, the Crawler and the Screenshot API: ProxyPool::Basic, ProxyPool::Unblocker, ProxyPool::UnblockerUltra or ProxyPool::Auto, each of which sets both the proxies and the Unblocker, or ProxyPool::PublicTorPool, the Tor network. The Screenshot API takes the first four and ignores any other value. Cloud Browser has pools of its own (see BrowserConfig).

The pool names written before the proxy pools (ProxyPool::PublicDatacenterPool, ProxyPool::PublicResidentialPool) are still accepted. The migration guide covers them: https://scrapfly.io/new-pricing#legacy-spellings

Non-exhaustive: the API grows this list, and a new member must not break a downstream match.

§

Basic

basic: datacenter proxies, Unblocker off.

§

Unblocker

unblocker: residential proxies with the Unblocker (anti-bot bypass) on.

§

UnblockerUltra

unblocker_ultra: residential proxies with the Unblocker on. The only pool accepted by the targets and anti-bot protections that have a price of their own: those refuse basic and unblocker with ERR::PROXY::UNBLOCKER_ULTRA_REQUIRED (HTTP 422, not billed).

§

Auto

auto: the API picks the pool before the request, from the target’s profile: the Unblocker on datacenter proxies, or the pool the target needs. Accepted on every target, the ones that require ProxyPool::UnblockerUltra included, where their price is added; priced as the pool it runs on.

§

PublicDatacenterPool

Former name of the datacenter pool.

§

PublicResidentialPool

Former name of the residential pool.

§

PublicTorPool

public_tor_pool: egress through the Tor network, the only pool that reaches .onion hidden services; also used for OSINT.
